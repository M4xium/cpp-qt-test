# BinaryXorProcessor

Тестовое приложение на C++/Qt для фоновой обработки файлов циклической операцией XOR с ключом длиной 8 байт.

## Возможности

- одна или несколько масок через пробел, `;` или `,` (`*.txt`, `.dat`, `testFile.bin`);
- однократная обработка либо периодический поиск новых/изменённых файлов;
- перезапись результата или автоматический суффикс `_1`, `_2` и т. д.;
- опциональное удаление исходника только после успешной фиксации результата;
- потоковая обработка блоками по 4 МиБ — файл целиком в память не загружается;
- отдельный рабочий поток, прогресс в 64-битных счётчиках;
- пауза и продолжение с текущего байта;
- безопасная остановка: незавершённый временный результат отменяется, готовый файл не повреждается;
- при закрытии программа будит приостановленный поток, останавливает работу и ожидает его завершения;
- настройки формы сохраняются между запусками.

В периодическом режиме неизменившийся входной файл обрабатывается только один раз за сеанс. Если размер или время изменения файла поменялись, он считается новым и обрабатывается снова.

## Правило XOR

Строка `1234567890ABCDEF` преобразуется в байты `12 34 56 78 90 AB CD EF`. Они циклически накладываются на файл с первого байта. Для неполного последнего блока используются только соответствующие первые байты ключа. Повторное применение того же ключа восстанавливает исходные данные.

## Сборка в Qt Creator 19

1. Откройте `CMakeLists.txt` через **File → Open File or Project**.
2. Выберите комплект **Desktop Qt 6.10.2 MinGW 64-bit**.
3. Нажмите **Configure Project**, затем **Build** и **Run**.

Сборка из терминала Qt:

```powershell
C:\Qt\Tools\CMake_64\bin\cmake.exe -S . -B build -G Ninja `
  -DCMAKE_PREFIX_PATH=C:\Qt\6.10.2\mingw_64 `
  -DCMAKE_MAKE_PROGRAM=C:\Qt\Tools\Ninja\ninja.exe
C:\Qt\Tools\CMake_64\bin\cmake.exe --build build
C:\Qt\Tools\CMake_64\bin\ctest.exe --test-dir build --output-on-failure
```

Для переноса `.exe` на другой компьютер рядом с ним нужно развернуть библиотеки Qt:

```powershell
C:\Qt\6.10.2\mingw_64\bin\windeployqt.exe build\BinaryXorProcessor.exe
```

## Ограничения и безопасность

Папки входных и выходных файлов намеренно должны различаться: это исключает случайное открытие одного файла одновременно на чтение и перезапись, а также зацикливание результатов в режиме таймера. Поиск выполняется в указанной папке без обхода подпапок.
